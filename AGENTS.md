# TINA Agent Bootstrap

Before non-trivial work in this repository, read and follow TINA_ENGINEERING.md.

TINA_ENGINEERING.md is the shared model-neutral execution contract for TINA.
This file is only a harness bootstrap and must not duplicate or redefine TINA
governance.

Resolve and obey committed tina-dev-factory governance before implementation.

When Agent Skills are supported, invoke tina-engineering after governance
preflight and before generic/global coding skills.

If canonical governance cannot be resolved or required evidence is unavailable,
return SAFE_PAUSE.

Do not weaken TINA gates because the active model, vendor, IDE, or harness
changes.
