# Architectural Caveat Assessment

Passage-level grounding remains out of scope and is not by itself a failure.

The class-enumerated architecture can be acceptable for Phase 10A when confirmed classes are closed broadly enough. Here, the confirmed classes are not closed broadly enough:
- filing_obligation misses common statement/follow-up/submit-anything formulations;
- filing_deadline misses common date/deadline formulations;
- tax_computation_basis misses semantically equivalent estate-base/deduction/threshold misstatements.

These are material P1 limitations because the remediation was specifically authorized to close those classes.
